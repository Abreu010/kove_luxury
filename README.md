# kove_luxury
Kove Luxury Streetwear é um e-commerce moderno de moda urbana premium focado em uma experiência de usuário limpa, elegante e responsiva. O projeto apresenta uma identidade visual minimalista e sofisticada, utilizando uma paleta de cores sóbria (tons de verde-escuro e off-white) para destacar o acervo de peças e as principais promoções da marca.
